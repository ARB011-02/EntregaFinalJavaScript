# TiendaTech – Simulador de compra online

Proyecto final de JavaScript (Diplomatura Full Stack).

**Flujo:** ver productos → buscar/filtrar → agregar al carrito → modificar cantidades → total → datos de entrega → confirmación.

## Cómo ejecutarlo
`fetch` no funciona abriendo el HTML con doble clic. Usá un servidor local (por ejemplo, la extensión **Live Server** de VS Code) o GitHub Pages.

## Estructura
- `index.html`
- `css/styles.css`
- `js/api.js` (fetch), `js/storage.js` (localStorage), `js/main.js` (DOM y lógica)
- `data/productos.json` (base de datos simulada)
- `assets/img/` (imágenes)

Librerías: Bootstrap, SweetAlert2 y Toastify.
